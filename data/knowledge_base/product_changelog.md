# Product Changelog and Release Notes

## Firmware 2.5 (released 2026-06-12)
- Improved Bluetooth pairing reliability.
- Filter-life reminders now appear in the app 14 days before the limit.

## Firmware 2.4 (released 2026-02-18)
- Changed the meaning of alert code E-05. Before 2.4, E-05 meant pump overheating. From 2.4 onward, E-05 means the RO membrane is saturated, and pump overheating is reported as E-07.
- Added TDS reading to the app dashboard.
- Units on firmware 2.3 or earlier still use the old meaning. Check the firmware version in the app under Device, then About.

## Firmware 2.3 (released 2025-11-05)
- Fixed a rare tank-full sensor false alarm (E-02).

## Firmware 2.2 (released 2025-08-20)
- Added the leak sensor alarm (E-06).

## Firmware 2.0 (released 2025-03-10)
- First release for the AquaPearl 500 Pro.
